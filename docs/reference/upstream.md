# Interface baseline

Routes and the bundled OpenAPI contract were inspected at [AstrBot commit `6b10af75e118714335aff3aab047bf7689fa1388`](https://github.com/AstrBotDevs/AstrBot/commit/6b10af75e118714335aff3aab047bf7689fa1388).

Bundled contract: 245 paths. Legacy catalogue: 223 operations. The server's own OpenAPI takes precedence. A catalogue entry is not an end-to-end compatibility guarantee. Dynamic plugin routes and WebSocket-specific protocols need dedicated extensions.
