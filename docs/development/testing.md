# 测试与安全

## 自动检查

质量流水线在所有提交与 PR 上执行：

- JVM 单元测试：能力探测、登录隔离、MD5 显式模式、权限/协议失败、不重放写入、路径编码、JSON Schema、预设、脱敏、补全与大小限制。
- Google Java Format / Spotless 与 Android Lint。
- debug APK 编译。
- 文档构建与仓库契约检查。
- 全历史 Gitleaks 扫描。

这些测试不等于完整 AstrBot 端到端测试。正式发布前应在真实测试服务器验证下表，不能将“目录中有接口”标成“功能测试通过”。

## 手工发布矩阵

| 场景 | 检查内容 |
| --- | --- |
| 当前新版 /api/v1 | 密码、两步验证、API Key scope、读取与写入 |
| 代表性旧版 | 无 OpenAPI 探测、原文/MD5 协议、接口缺失 |
| Android 8 / 12 / 14 / 15 | 添加连接、旋转、后台恢复、软键盘、全屏编辑 |
| 多连接 | 凭据隔离、切换补全清空、预设目标检查 |
| 插件 HTML | 页面令牌、同站资源、拒绝跨站、bridge 限制 |
| 异常网络 | 超时、取消、TLS、反向代理子路径 |
| 签名升级 | 用上一发布包覆盖升级，保留本地数据 |

## 处理秘密

应用禁止系统备份，凭据和预设 AES-GCM 加密存储。默认响应展示对常见密钥字段脱敏；这不是任意秘密识别器。导出的原始响应可能含秘密。

贡献者不得提交真实服务器凭据、Keystore、私钥或完整生产配置。安全问题的报告方式见仓库 `SECURITY.md`。
