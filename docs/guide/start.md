# 开始使用

## 安装

从仓库 Releases 下载维护者签名的 APK，允许安装来自该来源的应用。开发测试可使用 Actions 的 debug APK；debug APK 与正式签名不同，不能直接互相覆盖安装。

最低 Android 8.0。应用不需要无障碍、Shizuku、存储全盘访问或 root。

## 第一个连接

1. 在 AstrBot 主机确认 WebUI 正常工作，并取得服务地址和账户。
2. 点击“添加连接”，填写完整地址，例如 `https://bot.example.com`；反向代理支持 `https://example.com/astrbot`。
3. 填写用户名与密码，或具有足够 scope 的 API Key。用户名以你的 WebUI 实际配置为准。
4. 保存后点击“连接”。新版使用原文密码登录；明确要求 MD5 的旧版在连接设置中切换模式。
5. 如果启用两步验证，首次自动连接会提示未完成，随后在连接页填写验证码并再次连接。

不要把地址写成浏览器页面的 `/#/...`。服务器防火墙、反向代理和 VPN 必须允许手机访问。

## 基本操作

连接成功后进入“管理”：通用设置、配置文件、人格与提示词、模型服务、MCP 服务、机器人平台和插件管理均提供原生入口。

进入条目后先读取当前配置，再通过开关、下拉选择、数字输入和逐项列表编辑。长提示词可展开到全屏。修改先留在草稿中，点击底部“保存更改”并确认后才写入服务器；返回时会提醒尚未保存的修改。

插件列表提供启停开关。需要未适配功能时，在“工具 → 高级工具”使用接口浏览器或自定义请求。

应用允许截图和录屏，错误弹窗支持复制错误详情，便于反馈问题。分享前请自行检查画面中是否含敏感配置。响应文件中的原始内容也可能包含秘密。

## 应用更新

在连接主页进入「设置 → 应用更新」，可以立即检查版本、切换更新渠道，以及开启启动检查或自动下载。启动检查默认每天一次；预发布/开发版本默认接收预发布，正式版本默认只接收正式版。自动下载默认关闭，仅在应用打开时执行，不注册常驻后台服务。

更新来自本项目公开的 GitHub Releases。下载后会校验 SHA-256、包名、递增版本号和当前签名，安装时由 Android 显示确认页面。首次安装更新需要在系统设置允许本应用安装未知来源应用，返回后继续安装。更新不会清除连接或配置。签名不同会停止更新，避免覆盖失败；早期本地测试 APK 与 Actions 正式签名不同，需要自行迁移到同一签名系列。旧 Release 没有更新清单时不会被推荐；私有仓库或网络不可达会在手动检查时显示原因。

## 语言、外观与字段说明

「设置 → 外观」可选择跟随系统、简体中文或 English，切换浅色/深色，并通过色板或 `#RRGGBB` 自定义主题色。应用重新显示主页后生效，本地连接与预设保留。输入框内的实际配置值不参与翻译。

设置项旁的 `ⓘ` 显示字段标识、类型、服务器提示、默认值、范围与枚举等说明；原始字段标识保留，方便和 WebUI 对照。内置 API 操作提供中文名称，参数说明包含权限 scope、是否写入以及参数规则。服务器新增的未知字段和第三方 HTML 页面仍由服务器/插件提供文案，不会把用户提示词或插件代码当作界面文字翻译。

0.2 架构首次需要安装 APK。之后兼容的核心更新只下载脚本并重新加载界面；原生能力变化仍需系统安装 APK。可在应用更新中查看核心版本与架构指纹、回退核心，详情见[脚本核心与架构版本](/development/script-core)。
