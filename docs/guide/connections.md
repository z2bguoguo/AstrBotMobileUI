# 连接与兼容性

## 能力探测

客户端先请求 `/api/v1/openapi.json`。成功时使用服务器自身契约；仅在该只读探测返回 404 或 405 时选择独立的旧版目录。500、TLS 错误和返回 HTML 的代理错误不会被当成旧版本。

不对失败的写入自动换接口重试，避免重复安装、发送消息或删除资源。旧版没有完整机器可读契约，目录中的接口仍可能不属于目标版本；404 会明确显示“不提供此接口”。

## 登录方式

| 方式 | 用途 | 注意 |
| --- | --- | --- |
| 原文密码 | 当前新版 WebUI | 通过 HTTPS 保护传输 |
| MD5 模式 | 明确要求散列的旧版 | 手动选择，不因密码错误自动重试 |
| API Key | 新版受限 API | 使用 `X-API-Key`；缺少 scope 的操作返回 403 |

每个连接的 HTTP 客户端独立维护 Cookie 与令牌。WebView 不接收账户密码和全局 JWT。

## 版本声明

当前基线来自仓库记录的 AstrBot 修订版本。**未验证所有历史版本**。服务器契约自适应是兼容策略，不是任意老版本保证。请在反馈中提供版本、HTTP 方法、路径和脱敏错误，不要上传账户密码或完整配置。

地址与密码保存在 Android Keystore 加密的本地存储中；不支持跨设备恢复密钥。卸载会丢失本地配置。支持明文 HTTP 是为了局域网，但请仅在可信网络使用。
