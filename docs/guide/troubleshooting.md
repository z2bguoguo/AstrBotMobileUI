# 排错

| 现象 | 检查步骤 |
| --- | --- |
| 地址不合法 | 使用 http(s) 完整地址，删除账号、查询字符串与 `#` 片段 |
| 401 | 重新连接，检查密码模式、账户和两步验证码 |
| 403 | 检查 API Key scope；必要时用具有权限的 WebUI 账号 |
| 404 | 确认服务器提供此接口；旧版目录不代表所有旧版都有同一接口 |
| 返回 HTML | 检查代理地址是否指向 WebUI 根路径，是否被登录网关劫持 |
| TLS 错误 | 使用有效证书或在系统信任链正确安装证书；客户端不绕过 TLS |
| 写入超时 | 重新读取状态；不要立即重复提交 |
| 文件过大 | 使用 WebUI 或对应服务器分块协议；通用页不会自动拆文件 |
| 本地配置无法解密 | Android Keystore 或数据异常；不要覆盖原数据，可重新配置应用 |
| 更新提示签名不同 | 正式与 debug 包不能覆盖；维护者也必须一直使用原签名 |

提交 Issue 时写明 Android 版本、AstrBot 版本、失败路径及预期行为。日志、配置和响应先脱敏；不应附带密码、Token、Cookie、API Key 或签名文件。
