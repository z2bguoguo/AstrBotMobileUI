# 插件自定义 HTML

在工作空间选择“插件自定义 HTML 页面”，输入插件名与 View 名。可先读取插件详情找到服务器公开的页面信息。

新版入口使用 `/api/v1/plugins/{plugin}/views/{view}`，旧版使用 `/api/plugin/page/entry`。服务器返回 `content_path` 后，客户端只打开同一实例 `/api/` 下的页面，使用页面专属令牌。自定义服务器可借助手动 API 查看入口响应。

HTML 在专用 WebView 中运行，启用 JavaScript 与 DOM 存储，禁用本地文件访问、跨实例导航、第三方资源和混合内容。不忽略证书错误，不向页面暴露原生文件或账户凭据。

## 限制

已适配 AstrBot WebUI 的 `apiGet/apiPost` 请求桥接，凭据保留在原生网络层，只允许调用当前插件的扩展命名空间。文件上传/下载与 SSE 桥接尚未实现，会返回明确错误。要求 CDN、外部登录或第三方资源的页面会被当前同实例限制阻止；应由插件作者将依赖打包到插件资源。当前不宣称任意历史 HTML 页面均兼容。

如果页面空白，检查服务器版本、插件激活状态、View 名和资源是否本地打包。可回到 WebUI 使用该插件。
