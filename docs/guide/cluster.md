# 集群与预设

## 分组管理

每个保存的连接含独立标识、地址、用户名/密码或 API Key。主页按分组和名称排序，可搜索名称、分组和地址。编辑连接的分组即可移动，复制已保存连接会创建新标识，之后的修改互不影响。

## 传递配置

1. 连接来源实例，读取配置或找到对应修改操作。
2. 将要复用的内容填入请求，点击“保存为预设”。
3. 默认清空字段名包含 password、token、secret、API key 等的值；如果确实需要传递，可明确勾选保留密钥。预设仍加密存于本机。
4. 返回主页，连接目标实例，在预设库选择“加载到当前实例”。
5. 客户端要求方法和路径存在于目标目录。检查目标资源 ID、插件名称、模型名和路径参数，再确认执行。

预设不包含 WebUI 登录 Cookie 或 JWT，也不会自动将源实例的登录态带到目标。动态配置中并非所有秘密都能靠字段名识别，请自行检查。不同版本的请求体不自动迁移，分组也不会触发无人确认的批量写入。

如果同一路径不存在，使用目标操作页手动迁移字段。可复制预设 JSON 修改名称及参数，然后保存为新预设。
