## 提示词与 MCP

进入“管理 → 人格与提示词 / MCP 服务”，选择条目后直接编辑字段。字符串按原文保存；对象和数组必须是合法 JSON。对提示词字段点击“全屏编辑”，不会把换行强制改成空格。

设置页支持布尔开关、枚举选择、数值输入、嵌套分组与列表逐项编辑。所有未修改字段会保留，编辑不会立即修改服务器。

全屏编辑器提供字符数、行数、修改状态、查找、全部替换、恢复进入前内容。JSON 模式可格式化。保存先回写当前表单，随后再显式执行接口；编辑器不会直接修改服务器。

群号、UMO 与 URL 检查只提供建议。不同平台的群标识可能为 `group:123`，也可能包含平台名或完整 UMO；客户端不擅自补前缀。

## 执行与结果

GET 只读请求没有请求体。POST/PUT/PATCH/DELETE 会预览目标与数据。服务器返回 200 但 `status:error` 时同样视为失败。超时或取消后，服务器可能已处理写入，应重新读取确认后再操作。

## 运行状态

运行概况与资源占用分组显示。CPU 和明确标注为百分比的指标附有进度条；运行时间合并为天、小时、分钟和秒；秒/毫秒启动时间戳按手机时区显示。内存、磁盘字节数按 B、KiB、MiB、GiB 自动换算。旧版 AstrBot 的 `memory.process` / `memory.system` 单位为 MiB，分别表示进程内存和系统总内存，进度条标注为两者占比，不代表系统整体内存使用率。

缺失指标显示空值或不展示进度条，不用零代替未知数据。未知字段保留上下文；「原始状态」可查看隐藏常见密钥后的完整返回。配置分组缺少服务器翻译时，使用本地中英文名称补充，实际字段键和用户输入不会被改写。

## 自动刷新、实时日志与插件市场

运行概览可按连接保存刷新间隔，默认 10 秒；输入 `0` 关闭自动刷新，支持 5–3600 秒的整数。刷新只替换状态区域，失败时保留上次数据。离开页面或应用进入后台会停止请求，返回前台后恢复；“立即刷新”可随时手动读取。

在管理页打开“实时日志”。客户端先读取近期历史，再连接服务器 SSE 日志流；断线后按退避策略自动重连，并通过事件游标请求缓存补发。可暂停接收、按级别筛选、搜索或清空本地显示。最多保留 300 条及 256 Ki 字符，显示最近 100 条，单条显示长度有限。日志不写入本机持久存储；清空显示不会删除服务器日志。补发范围受服务器缓存限制，不能保证离线期间完整保留全部日志。反向代理需要允许长连接并关闭 SSE 缓冲。

插件市场读取当前服务器所配置的市场，支持搜索名称、作者、描述和标签、星标/名称排序、已安装筛选及分页。详情页展示来源、版本要求和安装状态；仓库链接在浏览器打开。安装前会显示插件名称、来源及目标实例，确认后才向服务器发送一次安装请求，服务器版本检查保持开启。可按需要填写下载代理。安装失败请结合实时日志排查，客户端不会自动重放安装请求。

状态和日志需要 API Key 的 `system` 范围；市场查询与安装需要 `plugins` 范围。旧接口可能只接受 WebUI 账户登录。客户端仅在读取接口明确返回 404/405 时尝试旧路由，不会因 401/403 自动绕过权限。

本次新增底层持续读取与生命周期调度能力，旧架构需先安装包含该能力的完整 APK；后续兼容架构的页面和规则可继续只更新签名脚本核心。当前使用固定上游接口与模拟服务验证；不代表已经在所有历史 AstrBot 版本或真实生产服务器验证。
